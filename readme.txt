C500G Desk
ipTIME C500G용 비공식 Windows 다중 CCTV 뷰어
버전: 1.4.2 / GitHub 공개용 소스

휴대폰 ipTIME CCTV 앱 계정으로 여러 카메라의 영상과 소리를 확인하고,
방향 버튼을 누르는 동안 PTZ를 조작하는 Windows 프로그램입니다.
계정 P2P 연결과 별도의 RTSP 직접 연결 방식을 지원합니다.
제조사의 공식 프로그램은 아니며 실기 확인 대상은 C500G입니다.

1. 이 공개본에 포함된 것
-----------------------
- C# WinForms 앱과 C++ SDK 브리지 소스
- 카메라 목록 4 / 9 / 12 분할 화면, 페이지 전환, 화면 밖 연결 유지
- 계정 영상, 선택한 카메라의 소리, 음량 및 음소거
- PTZ 누르는 동안 연속 이동 / 놓으면 정지
- 선택적 자동로그인, 시작 시 설정된 모든 CCTV 연결
- 연결 끊김과 장시간 버퍼링 감지 및 카메라별 자동 재연결
- 빌드 스크립트와 실제 카메라에 접속하지 않는 회귀 검사

개인 카메라 주소, 기기 ID, 초기 카메라 자동 등록 및 특정 기기용 설정
보정 코드를 제거했습니다. 새 설치는 빈 카메라 목록으로 시작합니다.
자기 계정에 로그인하거나 직접 연결 카메라를 추가해서 사용합니다.
기존 PC의 사용자 설정이 있으면 해당 설정은 그대로 읽습니다.

이 ZIP은 소스 배포본입니다. 실행 파일, 외부 SDK, 앱 계정 정보,
서비스 인증값, 기존 로그·CCTV 화면·분석 원본은 포함하지 않습니다.
계정 모드를 실행하려면 외부 SDK와 아래의 서비스 연동 설정이 필요합니다.

2. 실행 환경과 외부 구성 요소
----------------------------
- Windows 64비트 / .NET Framework 4.x
- 계정 모드: C500G.ModernIoTBridge.dll과 검증 대상 x64 SDK 전체
- RTSP 모드: 공식 ipTIME CAM Multi Viewer의 64비트 영상 재생 구성 요소

계정 SDK 연동 기준은 Yoosee 1.0.0.14 IOT_LIB x64입니다.
파일명과 해시는 native\modern-sdk-manifest.json 및
src\CloudPtzController.cs에 있으며, SDK 종속 DLL도 함께 필요합니다.
임의의 다른 SDK 버전은 파일 검증 또는 연동에 실패할 수 있습니다.
SDK와 컴파일러는 이 저장소에서 내려받거나 설치하지 않습니다.

RTSP 영상 엔진은 현재 다음 설치 위치를 사용합니다:
  %ProgramFiles%\ipTIME\ipTIME_CAM_Multi_Viewer
  libvlc.dll / libvlccore.dll / plugins 폴더
일반 VLC 설치만으로 위 구성이 준비되지는 않습니다.
계정 P2P 영상은 별도 SDK 영상 엔진을 사용합니다.

3. 서비스 연동 설정
-------------------
공개본에는 서비스 App ID와 App Token을 내장하지 않습니다.
계정 기능을 사용하려면 사용 권한이 있는 연동값을 로컬에서 준비하고,
앱 프로세스가 다음 환경변수를 읽을 수 있도록 설정해야 합니다:
  C500G_APP_ID
  C500G_APP_TOKEN

위 두 값은 휴대폰 앱 로그인용 이메일/비밀번호나 카메라 기기 ID가 아닙니다.
이 저장소에는 값을 발급하거나 자동 추출하는 기능이 없습니다.
환경변수가 없으면 계정 요청 전에 APP_CONFIG_REQUIRED 오류를 표시합니다.
직접 RTSP 연결에는 이 서비스 인증값이 필요하지 않습니다.
실제 값을 소스, README, 명령 기록, 이슈 또는 배포 ZIP에 붙여 넣지 마세요.

4. 빌드
-------
C# 컴파일러:
  %WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe

네이티브 브리지의 검증 기준은 MSVC 14.29.30133 x64 Release CRT와
Windows SDK 10.0.19041.0입니다. 다른 도구 버전의 SDK ABI 호환성은
별도 확인이 필요합니다.

개인 PC 경로는 스크립트에 고정하지 않고 인수 또는 환경변수로 받습니다:
  C500G_MSVC_ROOT          MSVC 버전 폴더(include, lib, bin이 있는 위치)
  C500G_WINDOWS_SDK_ROOT   Windows SDK 루트
  C500G_SDK_DIRECTORY      검증된 IOT_LIB.dll과 종속 DLL이 있는 폴더

해당 환경변수를 로컬에 설정한 뒤 프로젝트 루트의 PowerShell에서:
  .\native\build-modern-native.ps1
  .\build.ps1 -ModernPtz

또는 자기 PC의 실제 경로를 다음 인수로 직접 지정할 수 있습니다:
  .\native\build-modern-native.ps1 -CompilerRoot '<MSVC 폴더>' -WindowsSdkRoot '<Windows SDK 폴더>'
  .\build.ps1 -ModernPtz -SdkDirectory '<IOT_LIB SDK 폴더>'
위 꺾쇠괄호 값은 자리표시자입니다. 실제 경로로 바꿔야 합니다.

기본 결과:
  dist\Release\C500GDesk.exe
  dist\Release\C500G.ModernIoTBridge.dll
  dist\Release\modern-sdk-path.txt

출력 폴더를 바꾸려면 build.ps1에 -OutputDirectory를 지정합니다.
-ModernPtz 없이 실행하면 C# 앱만 컴파일하며 SDK 브리지를 구성하지 않습니다.
계정 모드에는 네이티브 빌드와 -ModernPtz 구성이 모두 필요합니다.

modern-sdk-path.txt는 빌드 PC의 로컬 SDK 절대 경로를 UTF-8 한 줄로 기록합니다.
앱을 다른 PC로 옮길 때는 그 PC의 SDK 폴더 또는 IOT_LIB.dll 경로로 바꿉니다.
이 파일과 dist는 .gitignore로 제외되며 공개 ZIP에도 들어 있지 않습니다.
빌드 스크립트는 SDK를 패키지에 복사하거나 설치 프로그램을 만들지 않습니다.

5. 사용 방법
------------
1) 실행 환경과 계정 모드용 외부 설정을 준비한 뒤 C500GDesk.exe를 실행합니다.
2) 휴대폰 ipTIME CCTV 앱 계정으로 로그인합니다.
3) '다음 실행부터 자동 로그인'을 선택하면 로그인 성공 후 암호화하여 저장합니다.
4) 로그인하면 계정에 등록된 카메라 영상을 자동으로 연결합니다.
5) 조작할 카메라를 선택하고 방향 버튼을 누른 뒤, 멈추려면 손을 뗍니다.

RTSP 모드에서는 카메라의 주소, 포트, RTSP 인증 정보를 추가하고 저장합니다.
계정 자동로그인을 사용하지 않는 시작 경로에서는 저장된 RTSP 카메라를 연결합니다.
휴대폰 앱 계정 비밀번호와 RTSP 비밀번호는 별도 정보입니다.
'모든 카메라 연결'은 정상 재생 중인 연결을 유지하고 미연결 대상을 연결합니다.
선택한 카메라의 소리만 재생하며, 볼륨과 음소거를 조절할 수 있습니다.

6. 자동 재연결
--------------
영상 오류·종료·중단 감지 후 처음 약 2초 대기하고 다시 연결합니다.
실패하면 4초 → 8초 → 16초 → 30초로 늘린 뒤 30초 간격으로 재시도합니다.
정상 재생이 30초 이상 이어지면 다음 장애의 대기 시간은 다시 2초입니다.
연결 중 또는 버퍼링이 25초 넘게 지속되는 경우에도 복구를 예약합니다.
실제 복구 시간에는 네트워크 및 SDK 처리 시간이 추가됩니다.

화면 밖 카메라도 복구 대상이며 여러 카메라는 재연결 시작 시점을 분산합니다.
타일의 남은 시간을 확인하거나 '재연결'로 즉시 재시도할 수 있습니다.
수동 연결 해제, 전체 해제, 로그아웃, 카메라 삭제 및 종료는 재시도를 취소합니다.
계정 인증 만료나 제어 모듈 종료 시에는 재로그인이 필요할 수 있습니다.

7. 사용자 정보 저장
-------------------
Windows 탐색기 주소창에서 다음 폴더를 열 수 있습니다:
  %LOCALAPPDATA%\C500GDesktop

자동로그인:
  cameras.xml.account-login.dat
직접 연결 카메라 설정:
  cameras.xml

자동로그인 아이디와 비밀번호는 DPAPI(CurrentUser)로 함께 암호화합니다.
일반 종료 시 유지하고 명시적으로 로그아웃하면 저장 정보를 삭제합니다.
다른 PC나 Windows 사용자로 파일을 복사하여 이전하는 방식은 지원하지 않습니다.
RTSP 비밀번호도 암호화하지만 카메라 이름·주소·ID 등은 읽을 수 있는 설정입니다.
사용자 설정, 백업, 로그인 파일은 암호화 여부와 관계없이 공개하지 마세요.
계정 로그인에는 서비스와의 네트워크 통신이 필요합니다.
자동로그인 대신 로그인 창을 열려면: .\C500GDesk.exe --login

8. 코드와 검사
--------------
src\                앱, 설정 저장, 영상, PTZ 및 재연결
native\             C++ 브리지, SDK 파일 메타데이터와 빌드 스크립트
tests\              합성 데이터와 가짜 연결을 사용하는 오프라인 검사
build.ps1           C# 앱 빌드
.gitignore          로컬 설정, 외부 DLL, 빌드 결과와 로그 제외
PUBLICATION_REPORT.txt  공개본 정리 및 검증 결과

프로젝트 루트 PowerShell에서:
  .\tests\RunRegression.ps1

검사는 실제 계정으로 로그인하거나 실제 카메라를 움직이지 않습니다.
일부 WinForms 검사 창이 잠깐 표시될 수 있으며 합성 화면과 설정만 사용합니다.
결과물은 artifacts\tests에 생성되며 Git에 포함되지 않습니다.
오디오의 실제 재생과 네트워크 단절 복구는 별도 실기 확인이 필요합니다.
가상 13대 구성 검사는 실제 동시 연결 용량을 보장하지 않습니다.

기존 실기 확인: C500G 계정 영상·소리, 연속 PTZ 이동·정지, 전체 자동 연결.
이 공개본의 서비스 환경변수 방식은 합성 입력으로 검증했습니다.
공개본으로 실제 계정 로그인이나 카메라 연결을 다시 수행하지는 않았습니다.
